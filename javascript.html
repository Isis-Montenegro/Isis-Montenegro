🟨 Ecosistema Web en JavaScript

Aplicaciones interactivas, manipulación del DOM y lógica de videojuegos.

🕹️ 1. Arcade "Cazando" (Juego Interactivo)

Videojuego web desarrollado con HTML5 y JS. Implementa motor de físicas de colisión, temporizador en tiempo real (setInterval), control por teclado y un sistema de niveles con aumento de dificultad progresiva.

🚀 Ver Proyecto en Vivo

💰 2. Simulador de Créditos Financieros

Aplicación de tecnología financiera (Fintech) que procesa inputs del usuario para calcular capacidad de pago, aplicar fórmulas de interés y proyectar cuotas mensuales. Usa manipulación directa del DOM para renderizar tablas dinámicas.

🚀 Ver Proyecto en Vivo

🏆 3. Dashboard de Torneos Gamer

Plataforma de gestión competitiva que procesa arreglos y estructuras de datos en JavaScript para registrar participantes, generar métricas y renderizar la interfaz de forma dinámica sin recargar el navegador.

🚀 Ver Proyecto en Vivo

🐍 4. Videojuego Clásico Snake

Recreación del clásico juego Snake. Destaca el uso de matrices para el cuerpo de la serpiente, lógica de colisiones con los bordes y control preciso de fotogramas por segundo utilizando bucles de actualización en JavaScript puro.

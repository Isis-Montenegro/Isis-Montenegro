⚙️ Mis Proyectos con Arduino

Haz clic en cada título para desplegar los detalles.

🚧 Barrera Automatizada (ESP32-CAM)

Sistema mecatrónico diseñado para el control de acceso utilizando visión por computadora embebida. Detecta colores en tiempo real para levantar una barrera usando un micro-servo SG90.

💃 Robot Bailarín Bípedo

Sistema de robótica móvil construido con Arduino y control de potencia mediante drivers L298N, ajustando cinemática para secuencias de movimiento.

🤖 Robot Seguidor De Linea

Plataforma robótica que utiliza sensores ultrasónicos para escanear su entorno y recalcular rutas de forma autónoma.

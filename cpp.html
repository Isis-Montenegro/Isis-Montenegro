🟦 C++ y Sistemas Embebidos

Desarrollo de firmware, control de actuadores y procesamiento de sensores a bajo nivel usando el framework de Arduino y microcontroladores ESP32.

💃 1. Robot Bailarín

Hardware: Arduino Uno, Driver de Motor L298N, Motores DC.
Lógica C++: Sistema de robótica móvil enfocado en el control de secuencias y cinemática. El código en C++ gestiona los estados lógicos de los pines hacia el puente H para controlar la dirección, velocidad y tiempos de activación de los motores, generando rutinas de movimiento predefinidas y sincronizadas.

🚧 2. Barrera Automatizada con Visión Artificial

Hardware: Microcontrolador ESP32-CAM, Servomotor SG90, LED Bicolor, Regulador 5V, Baterías Li-ion 18650.
Lógica C++: Sistema Edge AI para control de acceso. El firmware inicializa la cámara, captura frames en formato QQVGA RGB565 y escanea iterativamente la matriz de píxeles. Al detectar la firma de color calibrada (rojo), el algoritmo dispara la lógica PWM del servomotor para abrir la barrera y conmuta el estado del LED.

📂 Ver Código en GitHub ▶️ Ver Demostración

🏎️ 3. Seguidor de Línea

Hardware: Arduino Uno, Sensores Infrarrojos (IR), Driver de Potencia L298N.
Lógica C++: Sistema de control reactivo basado en lecturas digitales de reflectancia. El código C++ evalúa simultáneamente múltiples variables de los sensores IR para corregir la trayectoria del robot en milisegundos, ajustando el giro y tracción de las ruedas según los requerimientos de la pista.
